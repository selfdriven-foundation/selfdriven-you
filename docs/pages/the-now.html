01 · The trick of tomorrow

Tomorrow never comes.
Today always does.

"Tomorrow" feels like a plan. It's a parking spot. Nothing gets done there, but it feels handled, which is exactly why it's so easy to keep using.

— i —

You're already living in a tomorrow

Look at the date. At some point you called this "tomorrow" and moved something into it. It's now. Whatever you deferred is due, or it's being deferred again.

— ii —

Future-you isn't a different person

The version of you who'll "feel like it tomorrow" has the same energy, the same phone, the same doubts. Waiting isn't a strategy. It's a rehearsal for waiting.

— iii —

Now is the only place you can act

You can plan for the future and learn from the past, but you can only move in the present. Every real thing you've ever done, you did in a now.

02 · Now, in four modes

Bring today forward.

Each mode has a version of tomorrow it hides behind. Each one has a two-minute move that collapses it into now.

Curious

explore · ask · learn

The tomorrow: "I'll look into it later." Later is where interest goes to cool down. The tug you feel now is the strongest it will ever be.

Two-minute moveAsk the question right now. Send it, search it, or write it down where you'll trip over it today.

Caring

listen · hold space

The tomorrow: "I'll call them this week." People don't get your good intentions. They only get the message that actually arrives.

Two-minute moveMessage the person you've been meaning to. No ask attached. Just "thinking of you."

Constructive

build · ship · move

The tomorrow: "I'll start when I've got a clear run." The clear run isn't coming. Momentum is made from small, rough starts in interrupted time.

Two-minute moveDo the single smallest next action on the stuck thing. Open the file. Write the first line. That's it.

Chill

pause · breathe · reset

The tomorrow: "I'll rest once this is done." It's never done. Rest deferred isn't saved up, it's spent as burnout.

Two-minute moveTen slow breaths, eyes closed, right now. Not after this page. Now.
